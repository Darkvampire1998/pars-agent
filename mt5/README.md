# کانکتور ورود با رمز MT5

این کانکتور با SDK رسمی MetaQuotes به **یک ترمینال نصب‌شده** وصل می‌شود. برای هر حساب، ترمینال، پوشه کانکتور و state جدا لازم است. پنل روی VPS لینوکس باقی می‌ماند. SDK رسمی Windows x64 است؛ نصب آن در Python بومی لینوکس پشتیبانی نمی‌شود.

## اتصال از پنل

۱. در «حساب و اتصال»، نام حساب، شماره ورود، نام دقیق سرور بروکر، سرمایه مبنا و رمز معاملاتی را وارد کن. حساب جدید با پروفایل محافظه‌کار و حالت فقط تحلیل ساخته می‌شود. رمز رمزگذاری می‌شود؛ در پاسخ‌های پنل نمایش داده نمی‌شود.

۲. Account ID و کلید اتصال را خصوصی ذخیره کن. برای حساب قبلی، ابتدا ایجنت را متوقف و رمز را در فرم «ورود کانکتور» ذخیره کن؛ این کار کلید قبلی را باطل می‌کند.

۳. «دانلود کانکتور MT5» را بزن. بسته منتشرشده شامل کد و wheelهای Windows Python 3.12 x64 است و برای نصب وابستگی کانکتور به PyPI نیاز ندارد.

۴. روی Windows x64، Python 3.12 رسمی و ترمینال MT5 **بروکر خودت** را نصب کن. بسته را در پوشه‌ای اختصاصی خارج از پوشه عمومی باز کن. در PowerShell اجرا کن:

```powershell
& .\setup.ps1
```

آدرس HTTPS پنل، Account ID، کلید اتصال و مسیر کامل `terminal64.exe` را وارد کن. رمز MT5 از پنل با HTTPS دریافت می‌شود؛ در فایل connector.json ذخیره نمی‌شود. فایل JSON حاوی کلید است؛ دسترسی پوشه را محدود نگه دار. پنل، رمز را فقط به کانکتور دارای کلید همین حساب و instance متصل می‌دهد.

۵. وضعیت ورود را در پنل بررسی کن. شماره حساب، سرور، currency، balance و equity باید با ترمینال بروکر تطبیق داشته باشند. حالت تحلیل بدون سفارش کار می‌کند؛ برای معامله دمو، مجوز معامله خودکار در ترمینال و حساب باید فعال باشد. ترمینال باید روشن و متصل بماند.

اجرای دوباره پس از setup:

```powershell
& .\.venv\Scripts\python.exe .\connector.py --config .\connector.json
```

برای اجرای خودکار، همین فرمان را در Task Scheduler با **همان کاربر Windows و همان پوشه** قرار بده. هر حساب یک task و یک terminal جدا؛ کانکتور حساب‌ها را در یک ترمینال جابه‌جا نمی‌کند.

## Linux همراه Wine

این مسیر به Wine x64، محیط نمایش (یا Xvfb)، ترمینال بروکر و **Windows Python 3.12 x64 داخل همان Wine prefix** نیاز دارد. فایل‌های Linux Python قابل استفاده نیستند. آماده‌سازی Wine/ترمینال خودکار یا آزمایش‌شده روی VPS کاربر اعلام نمی‌شود.

پس از آماده‌سازی prefix مستقل، wheelهای بسته را با Windows Python همان prefix نصب کن. سپس کانکتور را با `wine <windows-python.exe> connector.py --config connector.json` اجرا کن. مسیرهای terminal_path در connector.json باید مسیر Windows قابل دسترسی در همان prefix باشند. برای اجرای بدون دسکتاپ و سرویس، نمونه `deploy/mt5-connector.service` و launcher زیر در مخزن موجود است:

```bash
WINEPREFIX=/home/mt5/.wine-pars bash mt5/run-wine.sh /path/to/windows-python.exe /path/to/connector.json
```

روی ARM، ترمینال MT5/Wine این بسته پشتیبانی نمی‌شود. بسته Docker پنل amd64/arm64 است؛ کانکتور SDK Windows x64 است.

## اجرای سفارش و بازیابی قطع اتصال

- تحلیل، دمو و واقعی جدا هستند. واقعی به تنظیم LIVE_TRADING_ALLOWED سرور، حالت live حساب و اجرای کانکتور با `--allow-live` نیاز دارد؛ تغییر پروفایل این مجوزها را فعال نمی‌کند.
- داده قدیمی، حساب متفاوت، نبود مجوز، حداقل لات بالاتر از بودجه، مارجین ناکافی، SL نامعتبر یا ریسک باز نامعتبر باعث رد سفارش می‌شود.
- journal قبل از claim نوشته می‌شود. OrderCalcProfit، مارجین و OrderCheck قبل از OrderSend بررسی می‌شوند. ثبت سفارش بروکر فقط **یک‌بار** انجام می‌شود؛ timeout، قطع اتصال و پاسخ نامشخص هرگز باعث ارسال دوباره نمی‌شود.
- نتیجه unknown ورود جدید را مسدود می‌کند. ابتدا ایجنت را در پنل متوقف کن، History و پوزیشن‌های بروکر را بررسی و نتیجه را در بخش تطبیق سفارش ثبت کن. سپس همان Python کانکتور را با `--ack-reconciled --config connector.json` اجرا و شناسه کامل سفارش بررسی‌شده را وارد کن؛ بعد کانکتور را دوباره اجرا کن. پاک کردن journal بدون بررسی بروکر مجاز نیست.
- حد ضرر/هدف روی بروکر باقی می‌ماند؛ توقف ایجنت یا کانکتور، پوزیشن‌ها را نمی‌بندد. امکان عبور زیان از SL در گپ، لغزش یا اختلال بروکر وجود دارد.

اتصال SDK واقعی و سفارش بروکر در این محیط آزمایش نشده‌اند. آزمون‌های خودکار از SDK ساختگی برای کنترل قرارداد، محاسبات و عدم ارسال مجدد استفاده می‌کنند. پیش از حالت واقعی، ترمینال بروکر و حساب دمو باید جداگانه آزموده شوند.
